# UX Contract

Primary screen is an investigation workspace, not a chatbot.

Desktop:
- Left: Product Context
- Center: Failure / Measurement / Regulatory State
- Right: Investigation / Evidence
- Bottom: “Tell Crado what you measured, changed or observed…”

Use progressive typed states:
- Processing measurement
- Correlation found
- Missing fact
- Hypothesis created/updated
- Observation added
- Before/after comparison
- Evidence state updated

Every hypothesis card must expose:
- hypothesis title
- confidence band, if used
- OBSERVED evidence
- KNOWN product facts
- INFERRED relationships
- MISSING evidence
- recommended next investigation, phrased as a suggestion for a qualified engineer

Do not expose chain-of-thought.
